01. 评测基准构造 (Benchmark)

采集真实多模块代码仓库，将核心接口定义随机埋入 15%、50%、85% 三个上下文深度区间，并在上下文中混入 6 个历史废弃版本的同名相似函数（Distractor APIs）以诱发真实工程幻觉。

02. 编码幻觉判定 (Hallucination Metric)

生成代码经由 Tree-sitter 静态语法树解析与编译器类型检查（cargo check / tsc --noEmit）。任何引用不存在的符号、虚构参数名或违背显式非空/生命周期约束均记为幻觉样本。

03. 为什么 983K 是关键测试点

百万级上下文窗口（1M = 1,048,576）扣除系统提示词、工具 Schema 与输出预留空间后，实际可用代码装载上限约为 983K Tokens，代表当前单次全量代码库喂入的极限边界。
