长上下文注意力衰减与编码幻觉实测报告

核心发现导语：通过对跨文件大型代码库（32K 至 983K Tokens）进行多跳依赖探针（Multi-Hop AST Needle）实测，研究证实前沿长上下文模型在突破 256K 临界点后会出现显著的「注意力稀释与中间带塌陷（Lost-in-the-Middle）」。当上下文逼近 983K 时，尽管单跳字面检索仍维持 78.2% 的表象召回率，但跨模块函数调用的符号保真度暴跌至 58.4%，诱发高达 31.8% 的编码幻觉率（主要表现为已废弃接口复苏、跨命名空间签名嫁接与隐式不变量丢失）。实验证明，单纯扩充窗口无法替代结构化注意力引导，而引入「AST 符号锚点索引 + 原文证据链强约束」可将 983K 极限窗口下的编码幻觉率压降至 7.9%。
